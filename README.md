# Console Banking System (Java & JDBC)

A console-based banking application built using Core Java, Object-Oriented Programming (OOP), JDBC, and MySQL database.

## Features
- Account Creation with PIN verification
- Deposit, Withdrawal, and Balance Enquiry
- Secure SQL Database Integration using PreparedStatements
- Exception Handling & Input Validation

## Tech Stack
- Core Java
- JDBC (Java Database Connectivity)
- MySQL
